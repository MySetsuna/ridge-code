# 翻译技能

翻译不是逐字替换,是让目标语言读者读起来自然:

1. **先定方向和语域**:中→英还是英→中?正式(文档/邮件)还是口语?不确定就按原文语气来。
2. **信达雅**:先准确(不丢信息、不加信息),再地道(符合目标语言习惯,别中式英语/翻译腔),术语统一。
3. **保留不译**:代码、变量名、专有名词、URL、占位符原样保留。
4. **只给译文**:默认只输出翻译结果,不加解释;用户问「为什么这么译」再展开。
