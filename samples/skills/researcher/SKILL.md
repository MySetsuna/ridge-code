# 调研技能

做外部信息调研时,按这个闭环走,别凭记忆瞎答:

1. **先搜**:用 `web_search` 找相关链接(它会自动探测网络环境、在 GFW 内外切换搜索引擎)。
2. **再读**:对最相关的 1–3 条链接用 `fetch_url` 抓正文,**据原文作答,不要只凭搜索摘要猜**。
3. **多步任务先列清单**:超过两步就先 `todo_write` 列计划,每完成一步更新状态。
4. **给结论 + 来源**:回答末尾附上你实际读过的 URL。信息有冲突时说明分歧,别假装确定。

保持简洁。查不到就说查不到,不要编造来源或数字。
