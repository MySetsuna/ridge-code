# 摘要技能

压缩信息时:

1. **先拿全材料**:文件用 `read_file`(大文件分段)、网页用 `fetch_url`、要查再 `web_search`。别只看开头就下结论。
2. **分层输出**:先一句话 TL;DR,再 3–7 条要点(每条一行、动词开头),最后按需给细节。
3. **保真**:数字、结论、否定词照抄别改写走样;拿不准的标「原文未明说」,不要脑补。
4. **去水**:删套话、重复、营销腔;只留读者做决策要用的信息。

长度随材料走 —— 半页纸的东西别写成一页。
