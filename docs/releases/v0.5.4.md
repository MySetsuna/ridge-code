# RidgeCode v0.5.4

## GitHub 快速安装

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/MySetsuna/ridge-code/main/scripts/install.ps1 | iex
ridgecode --version
```

Linux / macOS：

```bash
curl -fsSL https://raw.githubusercontent.com/MySetsuna/ridge-code/main/scripts/install.sh | sh
ridgecode --version
```

固定版本安装：把安装脚本 URL 中的 `main` 换成 `v0.5.4`，并传入对应的 `v0.5.4` 版本参数。安装器会校验 SHA256，并将二进制放入用户 PATH；完整命令、配置、TUI 快捷键与 MCP 用法见归档内 `README.md`。

## 本次稳定发布

- TUI 继续保留 Answer / Reasoning / Tool 分层展示、折叠详情、队列干预、双 Ctrl-C 接管退出与窄终端换行能力。
- `Ctrl+Space` 在支持键盘释放事件的终端中按住进入实时审计、松开回到尾部；旧终端自动沿用按键切换兼容行为。
- Error 终态保留已收到的部分 Answer、步骤与 token 元数据，便于恢复和排查。
- 发布资产覆盖 Windows x86_64、Linux x86_64/ARM64、macOS Intel/Apple Silicon；每个归档附带 SHA256 文件和 README。
