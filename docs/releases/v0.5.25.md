## RidgeCode v0.5.25

### 发布流程

- Release 仍由 deterministic quality gates 阻断：格式、workspace 测试、clippy、构建、coverage（≥80%）与报告上传均为必过项。
- 本次 Release 不依赖不可用的 `ridgecode-sonar` self-hosted runner；独立 `quality-gate` workflow 仍可在 runner 与 `SONAR_TOKEN` 齐备时执行 Sonar gate。

### 继承修复

- 保留 v0.5.24 的跨平台 `/doctor` 多行报告显示修复与取消竞态测试稳健化。
