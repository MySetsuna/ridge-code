# RidgeCode v0.5.6

## GitHub 快速安装

无需 Rust 或 Cargo，直接运行对应平台安装器：

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/MySetsuna/ridge-code/main/scripts/install.ps1 | iex
ridgecode --version
```

Linux / macOS：

```bash
curl -fsSL https://raw.githubusercontent.com/MySetsuna/ridge-code/main/scripts/install.sh | sh
ridgecode --version
```

需要可复现安装时，将脚本地址与参数固定为 `v0.5.6`。安装器下载对应平台归档、校验 SHA256，并把二进制放入用户 PATH；已有 `~/.ridge/config.json` 不会覆盖。

## 本次发布

- 收拢 Answer、Reasoning、Activity、Tool 的静态提交投影，保持 `flush_commits` 编排、工具折叠、历史回放与终端交互语义不变。
- TUI 保留换行、Reasoning/Answer 可检视、工具默认折叠、队列干预、双 Ctrl-C 接管退出与窄终端适配。
- 发布资产覆盖 Windows x86_64、Linux x86_64/ARM64、macOS Intel/Apple Silicon。
- 每个平台归档均附带 `README.md`、安装脚本及 `.sha256` 校验文件。

## 校验

```bash
gh release download v0.5.6 --repo MySetsuna/ridge-code --pattern 'ridgecode-*'
```

下载后按归档旁的 `.sha256` 文件校验，再解压运行 `ridgecode`。
