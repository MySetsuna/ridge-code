# RidgeCode v0.5.5

## GitHub 快速安装

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/MySetsuna/ridge-code/main/scripts/install.ps1 | iex
ridgecode --version
```

Linux / macOS：

```bash
curl -fsSL https://raw.githubusercontent.com/MySetsuna/ridge-code/main/scripts/install.sh | sh
ridgecode --version
```

固定版本安装：将安装脚本 URL 中的 `main` 换成 `v0.5.5`，并传入 `v0.5.5` 版本参数。安装器会校验 SHA256，将二进制放入用户 PATH，并保留已有 RidgeCode 配置。
