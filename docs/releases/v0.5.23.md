## RidgeCode v0.5.23

### 终端输入与 TUI

- Windows 默认 raw-VT 输入后端；保留 Crossterm 安全回退，并可用 `ridgecode terminal doctor` / `/doctor` 查看选择原因。
- 有界过滤碎片化 SGR mouse/focus 回报；普通 Enter、Tab、空格与字面量 `[I`/`[O` 不再误吞或增生。
- bracketed paste 与同次物理 CRLF 各提交恰一次；输入队列、接管、窗口缩放与渲染延迟均纳入 PTY Harness。

### 编排、Skill、MCP 与 A2A

- 增加调度预算、结构化失败分类、恢复策略及多轮 soak，避免无限重试、重复执行与取消竞态。
- Skill/agent/规则发现加入路径优先级、冲突来源、文件数/字节/token 上限；被覆盖 Skill 可用稳定限定命令调用。
- MCP 面板合并 Ridge 与宿主配置并脱敏；A2A 握手、认证、静默 peer 超时及并发边界更明确。

### Harness 与文档树

- provider 增加确定性有序流 Harness；eval 增加并发、恢复、预算与 phased gate 证据。
- SpecTree 规范树与 Obsidian 只读投影加入 hash、源码覆盖及 stale 检查。

- `cargo build --workspace --locked`
