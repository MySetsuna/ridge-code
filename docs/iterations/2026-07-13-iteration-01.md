## 1. 本迭代做了什么

从 NotebookLM 笔记本「手搓agent」提炼出 LangGraph Rust 化路线后,**推倒旧的 ridge-code(rc-* 一套成本优化编码 agent)**,重建为两层:

### `crates/langgraph` —— 手搓 Rust 版 LangGraph 引擎(纯图,零 LLM 依赖)
- `GraphState` trait = State + reducer:节点不直接改状态,而是返回 `Update`,由 `apply` 合并(强制显式合并语义,防并发丢更新)。
- Pregel **超步 + BSP** 执行环(`invoke_with`):每超步先克隆状态快照 → frontier 里所有就绪节点用 `tokio::spawn` **并发**执行(都看同一份快照)→ 同步点统一 reduce → 据合并后状态路由下一超步。
- `StateGraph` 构建器:`add_node` / `add_edge`(可 fan-out)/ `add_conditional_edge` / `set_entry`;`START`/`END` 虚拟节点;`compile` 校验入口与悬空边。
- `MemoryCheckpointer`:append-only 存每个超步快照,`get(step)` 可回读 → **时间旅行**。
- `StreamEvent` + `mpsc`:实时流式观测。
- `RunConfig.max_supersteps` → `GraphError::StepLimit`:防跑飞护栏。

### `crates/agent` —— 跑在引擎上的最小编码 agent(二进制 `ridge`)
- ReAct 图:`reason → act → verify`,两条条件边组成循环 + 反思环。
- **maker ≠ checker**:`reason`/`act` 生成,`verify` **独立**判定且只认确定性信号(工具输出的 `tests: passed`),不信模型自述。
- **双保险停机**:`MAX_STEPS` 硬回合上限 + `approved` 闸门,防死循环烧钱。
- `Brain` trait = 接真实 LLM provider 的接缝;当前是离线 `ScriptedBrain`(零联网可测)。
- `Tool` = `Arc<dyn Fn(&str)->String>`;当前是模拟「写代码先挂、修复后通过」的离线工具。

### 质量闸
- `cargo test --workspace`:**9 项全绿**(引擎 6 + agent 2 + doctest 1),含 BSP 并行合并、时间旅行、死循环熔断、坏循环到上限停机。
- `cargo clippy --workspace --all-targets -- -D warnings`:干净。
- `cargo fmt --all --check`:干净。
- CI(`.github/workflows/ci.yml`)三平台 build+test+clippy;release(`v*` tag)打 `ridge` 单二进制。

## 2. 架构现状

```
crates/langgraph  (纯图引擎)
  state.rs       GraphState(State + reducer)
  graph.rs       StateGraph / CompiledGraph / Pregel 超步执行环 / StreamEvent / RunConfig
  checkpoint.rs  Checkpointer / MemoryCheckpointer(时间旅行)
        ▲ depends on
crates/agent      (装配 agent 图 + 二进制 ridge)
  lib.rs         AgentState/Patch(reducer)、Brain trait、Tool、build_agent
  main.rs        demo:跑通闭环 + 打印每超步 checkpoint
```

demo 实跑轨迹:`reason#1 write_code → act 失败 → reason#2 fix → act 通过 → reason#3 finish → verify PASS`,`approved=true steps=3`。

## 3. 能力对照:距离 Claude Code 还差什么

以「媲美 Claude Code」为标尺,逐能力盘点(✅ 已有 / 🟡 有接缝未实现 / ❌ 未开始):

| Claude Code 能力 | Ridge 现状 | 说明 |
|---|---|---|
| 有状态图 / 循环编排 | ✅ | langgraph 引擎(超步+BSP+条件边) |
| 检查点 / 回滚 / 时间旅行 | ✅(内存) | 待:serde/bincode 落盘、跨进程恢复 |
| ReAct 循环 + 停机护栏 | ✅ | MAX_STEPS + approved |
| maker-checker 独立验证 | ✅(骨架) | 待:确定性验证器接真实编译/测试 |
| **真实 LLM 调用** | 🟡 `Brain` trait | 待:接 Anthropic/OpenAI,结构化输出 + 流式解析工具调用 |
| **工具:文件读写/编辑/shell** | ❌ | 只有一个 stub 工具;需真实 read/write/edit/bash |
| **MCP 客户端** | ❌ | 计划内嵌 `modelcontextprotocol/rust-sdk` |

| **Skill / 可复用指令** | ❌ | SKILL.md 机制 |
| **权限 / 沙箱 / harness** | ❌ | 工具权限门、Docker/gVisor/WASM 沙箱 |

| **流式 TUI** | 🟡 StreamEvent | 待:ratatui 实时视图订阅事件 |
| **成本/token 记账 + 预算熔断** | ❌ | loop engineering 的成本控制要素 |
| **持久记忆 / 长期记忆** | ❌ | 向量库 RAG / episodic memory |
| **hooks / slash commands** | ❌ | 生命周期钩子、命令系统 |
