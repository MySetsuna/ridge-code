## 做了什么

### 全局显示英化
- **tui.rs**:欢迎语/skip-danger 警示/恢复会话/中断/排队/审批(approved/rejected)/`run_command` 全部命令文案(`/help`、`/reset`、`/compact`、`/cost`、`/model`、`/models` 错误、`/jailbreak`、`/config set`、`/provider`、`/agent`、未知命令)/`swap_model`/`switch_provider` 提示/Panel 五标题与提示/`(未设)→(unset)`/`draw` 内输入框标题、浮窗标题、审批弹窗文案与标题、`⚠越狱→⚠JAILBREAK` 徽标、`fold_lines` 折叠标记、phase「推理中→reasoning」全部译英。
- **main.rs**:`--help` 全文、各 `eprintln` 日志(config/MCP/skill/sub-agent/provider/触发器/留痕/停机/信号)、`node_label`(reasoning/running tools/verifying)、headless status、`truncate` 标记译英。
- **保留中文**:代码注释(不显示)、`lib.rs` 模型侧串(BASE_SYSTEM/observation/BLOCKED = LLM 读,非显示)、测试里的 CJK 测试数据(`你好` 等,专测 CJK 处理)。

### banner 防「标识乱了」+ 美化
- 纯函数 `splash_block(width)`:宽 ≥ `SPLASH_W(48)` → **居中** ASCII 艺术字(逐行 `trim_end` 去尾空格 → 每行 ≤ width,`flush_commits` 的 `Wrap` 不再折行 → 消灭撕裂)+ 英文 tagline;窄 → 退化紧凑单行 `◆ RidgeCode`(极窄也不折)。
- 动画帧 `indent(splash_frame(...), splash_pad(width))` 与落定 banner **同居中偏移**,消除「揭示→落定」横跳。`SPLASH_TICKS` 10→14 更平滑。

## 对抗评审战果(正确性门禁)

- **不折行根因修在数据侧**:`splash_block` 保证每行 ≤ width(trim 尾空格 + 居中左缩进不超界),而非改 `flush_commits` 的通用 Wrap(避免误伤长文本换行)—— 最小面、无回归。
- **显示/模型分层**:只译**用户可见显示串**;`lib.rs` 模型上下文串不动,避免改 agent 行为或连锁破测。CJK 测试数据保留(它们正是验证 CJK 支持的)。
- **验收纯函数化**:`splash_block`/`splash_pad` 纯函数直断言宽度守卫;`has_cjk` 辅助验英化;零 PTY/wall-clock。
