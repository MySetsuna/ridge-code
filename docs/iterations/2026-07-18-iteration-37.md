## 做了什么

### 内置供应商 preset(纯静态数据,编进二进制)
- `PROVIDER_PRESETS`(14 条)`{id,label,kind,base_url,default_model,key_env}`:世界顶级 `openai/anthropic/gemini/grok`;中国顶级 `glm/kimi/deepseek/qwen/hunyuan/minimax`;聚合 `openrouter/siliconflow/together/groq`。除 Claude 走 `anthropic` 原生外,余皆 OpenAI 兼容端点——**接新 provider 免手敲 base_url/kind**。
- 纯核:`preset_by_id`(大小写不敏感)、`preset_to_profile`(api_key 恒 None)、`apply_login`(加/覆盖档 +(make_default)set 顶层四键 + **抹顶层残留 `api_key`** 防旧 key 配新端点认证错乱;产物绝不含 key)。

### `~/.ridge/auth.json` 密钥库
- `login` 存 API key 处,**独立于 config,key 不进 config**(既有「明文不因工具落 config」铁律保持)。按 `key_env` 索引,纯核 `auth_parse/auth_upsert/auth_get`(坏/空不崩、字符串值、OAuth 对象值前向跳过)。写盘 best-effort chmod 600(unix;非 unix no-op,不虚报)。`RIDGE_AUTH` 可指路径。
- key 解析新增一档:`resolve_key_env(name,&auth)` = env[name] 非空 或 auth[name];`ProviderProfile::resolve_key_with(&auth)` = 内联 `api_key` > 该档。`real_provider` 顺序:`RIDGE_API_KEY` → 顶层内联 `api_key` → **顶层 `key_env`→(env/auth)** → `providers[]`(auth-aware)。`build_agents`/TUI `switch_provider`/`current_api_key` 同步 auth-aware。Config 顶层新增可选 `key_env`(`--default` 用)。

### `ridgecode login` 子命令 + TUI `/login`
- CLI:`login [--list]` 列内置表;`login <id> [KEY] [--model M] [--name N] [--no-default]` → key 写 auth.json(缺 KEY 从 stdin 读一行,**绝不回显/落 argv/shell 历史**)+ 据 preset 写档 +(默认)设顶层默认。`main` 在解析任务前拦 `login`,免被当任务串。
- TUI:`/login`/`/login list` 列内置;`/login <id> <key>` 写 auth+config(`tui_login`)并**即时热切**到该 provider。补全表 + `/help` 挂上。
- **OAuth 订阅登录**:仅留接缝(auth.json 值可扩对象),本轮不落地(逐家 ToS 待专轮)。

### `/model` 合并(追加需求)
- `/model` 无参 → 实时模型页(原 `/models`);`/model <name>` → 直接热切。`/models`、`/model pick` 保留为**别名**(旧肌肉记忆),但补全表(`SLASH_COMMANDS`)与 `/help` 只呈现 `/model`。

## 对抗评审战果(正确性门禁)

- **auth.json 不破铁律**:「api_key 明文不落盘」铁律的真实语义是「序列化路径(`/provider add`/config 回写)不吐 key」,针对 config.json 卫生。`login` 要的持久化必须存 key,存进**独立密钥库**(opncode/gh/docker 同款)恰好两全:config 保持无 key,key 集中在收权限的专用文件。**改进**而非违背。
- **抹顶层 api_key 根因修**:`--default` 改顶层身份为新 preset 时,若不抹掉顶层残留内联 key(如现网 glm key),`real_provider` tier-2 会用旧 key 配新 base_url → 认证错乱。在 `apply_login` 数据侧一并 `root.remove("api_key")`,单点修净。
- **env 先于 auth**:显式 env 可临时覆盖已存的 key(aws/gh 惯例),不夺用户手动 override 权。
- **纯核化验收**:preset 表 / auth 库 / login 变换 / key 解析全纯函数直断言;无网络/PTY/wall-clock。model 默认串精确性非门禁(base_url/kind/key_env 才是接入正确性),用户随时可改。
