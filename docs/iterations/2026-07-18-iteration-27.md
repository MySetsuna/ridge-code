# Iteration 27 报告(UI 三部曲 II:高级输入 —— CSI u 多行 / 历史召回 / 补全浮窗)

## 做了什么(只碰 tui.rs + docs,合 contract)

- **CSI u**:enter 时 best-effort `PushKeyboardEnhancementFlags(DISAMBIGUATE_ESCAPE_CODES)`(不开 REPORT_EVENT_TYPES 免事件噪声),Drop 时 Pop。Shift+Enter / Alt+Enter / Ctrl+J → 插入换行;Alt+Enter 为免协议全平台降级主键(对抗评审修正:NLM 提的 Ctrl+J 在 unix legacy 与 Enter 同字节不可靠)。
- **InputState 输入状态机**:`{buffer, cursor(字符偏移), history, hist_idx, draft}` —— 光标处插删、Left/Right/Home/End、多行 Up/Down 列钳位、CJK 多字节安全;**首逻辑行 Up = 历史召回**(转换函数惯例),召回前存 draft、Down 走出还原;提交入会话历史;BPM 粘贴并入 `insert_str` 光标事务。渲染**真光标**(`Frame::set_cursor_position`,框内钳位)。
- **补全浮窗**:Tab 触发 —— 行首 `/` 词补斜杠命令(`SLASH_COMMANDS` 静态表),词内 `@` 补路径(单层 `read_dir`,候选 ≤20 有界,目录带 `/`);`filter_prefix` 稳序;浮窗态 Tab/↓ 下一项、↑ 上一项、Enter 应用(整词替换)、Esc 关、**字符/退格穿透**继续编辑;输入框上方有界渲染,青底高亮选中。
- **键位模态优先级**:审批 > 浮窗 > 输入,收进 `input_action(key, busy, popup_open)` 纯路由。
