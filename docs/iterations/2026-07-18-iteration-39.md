# Iteration 39 报告 —— Prompt 模板自定义命令 + Skills 显示为命令

> maker = 用户需求「自定义安装命令(Prompt 模板)+ Skills 显示为命令」。checker = CONTRACT-iteration-39。价值门禁不适用(用户明确需求)。

## 做了什么

### 命令核(lib.rs 纯函数)
- `SlashCommand{name,description,body}`;`parse_command_md(text,name)`(可选 frontmatter `description`/`desc`,余为 body;name 来自文件名);`expand_command(body,args)`(`$ARGS`→args;无占位且有参→追加);`load_commands(dir,skills)`(扫 `*.md` + 把每 skill 暴露为同名命令,**文件命令优先于同名 skill**);`resolve_command`。Config 加 `commands_dir`。

### 装配(main.rs + tui.rs)
- `load_configured_commands(cfg,skills)`:env `RIDGE_COMMANDS_DIR` > config > `~/.ridge/commands`;TTY 分支从同一 `&skills` 派生(含 skill-as-命令)后再移交 skills 给图,传入 `tui::run`。
- `tui::run` 加 `commands` 参 + `set_dynamic_commands`(`DYNAMIC_COMMANDS: OnceLock<Vec<String>>` set-once,`build_popup` 并入补全源;单测未设→空,不扰)。
- `run_command` 加 `commands` 参:末尾 `/` 分支从「未知命令」改为「解析 `/name args` → `resolve_command` → `expand_command` → 置 `ui.run_task`」;**内置命令仍先匹配,自定义命令无法 shadow 内置**。
- `ui.run_task: Option<String>`:主环**唯一提交点**取走 → 以任务身份起跑(`AgentState::new(展开body)`,note 显原始 `/cmd`),普通输入照旧。`/commands` 列全部命令。

## 对抗评审战果(正确性门禁)
- **内置不可被 shadow**:自定义命令派发放在所有内置 match 臂**之后**,`/model` 等永远命中内置 → 用户建个 `commands/model.md` 也无法劫持内置命令(安全默认)。
- **run_task 复用唯一提交点**:不新开任务 spawn 码 —— run_command 只置 `ui.run_task`,主环 iter-33 的唯一提交点消费(普通输入 or 展开命令),消除重复 spawn 路径。
- **动态补全零签名churn**:命令名走 set-once `OnceLock`(jailbreak AtomicBool 先例),不改 `build_popup`/测试签名;未设即退化静态表。
- **文件优先于 skill**:同名去重规则确定(文件覆盖 skill),`load_commands` 纯函数直断言。
