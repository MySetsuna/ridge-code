## 1. 新方向(来自 NotebookLM Studio 13 篇 notes)

Ridge 的北极星更新为:**通用 agent 执行框架 —— 加新能力 = 加一个 MCP server 配置 或 一个 `SKILL.md`,而非改 Rust 源码**。既能像 Claude Code 写代码,又能做**编程以外**的事(调研/日程/电商/生活)。四层解耦:内核(langgraph-rs 引擎)+ 协议(MCP 接万物)+ **知识(声明式 Skills)** + 协作(多智能体 maker-checker)+ 安全(权限门/危险命令拦截,沙箱待做)。已写入 `docs/DIRECTION.md` + `CLAUDE.md`。

## 2. 本迭代落地(知识层)

- **Skills 系统**:`Skill` 结构 + `load_skills`(扫 `~/.ridge/skills/*/SKILL.md`,解析 frontmatter + 正文)+ `build_system_prompt`(把技能注入 system prompt)。CLI 走 `RIDGE_SKILLS_DIR` / 默认 `~/.ridge/skills`;`build_llm_agent_full` = MCP + 权限门 + Skills 全装配。
- **通用化**:base system prompt 从「coding agent」放宽为「capable agent」;`verify_ok` 让开放式任务(模型 finish 且无失败信号)干净收尾,不再空转烧 token。
- **GLM 实测(非编程)**:放一个 `haiku` SKILL.md → `ridge "写首关于 Rust 的诗"` → 模型按技能写出严格俳句 + 签名「— ridge」→ `approved=true, steps=1`。**加 SKILL.md 就会做新事,零改代码。**
- 上一轮(Iter06)已达成:MCP 真接入(实测连 notebooklm-mcp 拿 39 工具 + GLM 调用)、trace.json 审计、`/compact`、危险命令拦截。
