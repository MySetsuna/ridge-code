# Iteration 23 报告(TUI 专轨第二刀:事件驱动环 + 有界日志)

## 做了什么(全部在 `crates/agent/src/tui.rs`,合 contract 边界)

- **事件驱动主环**:根除 `event::poll(50ms)` 固定轮询(grep=0)。阻塞读线程(`event::read()` → tokio mpsc)+ `tokio::select!` 六路复用(键盘/token/StreamEvent/审批/完成/tick);token 臂内 `try_recv` 批量排空免逐 token 一帧。
- **dirty 重绘**:`should_draw(dirty, busy)` —— 仅状态变更或 busy(spinner)才 `terminal.draw`;空闲零重绘、无事阻塞挂起。
- **纯决策函数**:`input_action(key, busy)`(Insert/Backspace/Scroll/Submit/Interrupt/Ignore;busy 时 Enter 不提交、Release 忽略)+ `tail_window(len, rows, scroll)`(视口尾窗区间,越顶钳住、极值饱和)。
- **有界日志**:`Ui.log` → `VecDeque` + `LOG_CAP=2000` 环形淘汰;`output_lines(rows, scroll)` 只构建窗口内行(O(rows)/帧替代 O(N)),滚动经尾窗不再用 Paragraph 偏移。
- 审批**请求**通道改 tokio unbounded 入 select;**应答**仍 std sync_channel(agent 侧语义不动)。
