## 做了什么(合 contract 触碰范围)

- **引擎 `CompiledGraph::invoke_best_of`**(langgraph/graph.rs):`Arc<Self>` + JoinSet 并发 N 分支各跑 `invoke_with`;失败分支丢弃(投机语义);评分器 `Fn(&S) -> i64` 择优、平分低索引确定性胜;空输入/全败 → 新增 `GraphError::NoWinner`;`RunConfig` 补 `Clone`。文档注明**无副作用隔离**边界 —— 不接 CLI 主流程。

- **动态输入高度**(tui.rs):`input_height(content, width, 3, 8)` 纯函数接入 draw 布局,粘贴多行内容输入框自动伸缩。
