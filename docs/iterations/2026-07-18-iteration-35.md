# Iteration 35 报告 —— 交互页框架:斜杠即弹 + 五命令搓成可搜索 Panel(配置页就地编辑)

> maker = 用户需求(斜杠自动补全、命令开交互页、页内搜索、配置页,「全套 + 就地编辑」)。checker = CONTRACT-iteration-35。

## 做了什么

- **斜杠/@ 即弹随打随滤**:`Insert`/`Backspace` 后重算 `build_popup` —— 打 `/` 立现全部命令、`/mo` 滤到 `/model*`,`@` 单层路径同理;余字符自然关窗(`build_popup→None`)。不再须先按 Tab(Tab 仍可显式触发)。
- **通用 `Panel` 交互页**(模态居中覆视口):`kind: PanelKind{Config|Provider|Tools|Models|Agent}` + 搜索框(随打随滤 `panel_filter`)+ 过滤列表(选中高亮)+ 提示行 + 选中动作。`Ui.panel: Option<Panel>`;键位模态优先级 = 审批 > **Panel** > 浮窗 > 输入(`panel_action` 纯路由,主环处理并 `continue`)。
- **五命令开页**:`/config`→配置页、`/provider[ list]`→Provider 页、`/tools`→工具页、`/models`\|`/model pick`→模型页(实时抓取)、`/agent`→sub-agent 页。构造 `config_panel`/`provider_panel`/`tools_panel`/`models_panel`/`agent_panel`。
- **配置页就地编辑**:↑↓ 选键 → Enter 进编辑(预填当前值)→ 输新值 → Enter `persist_config` 落盘 + **live 应用**(`apply_config_live`:provider/model/base_url 重 swap、status_bar 换底栏、allow_jailbreak 切开关;余键下次启动生效)→ 刷新页;Esc 取消编辑 / 关页。
- **动作**:Models=Enter `swap_model`+缓存 ctx_window;Provider=Enter `switch_provider`(抽取,`/provider use` 共用);Tools/Agent=只读浏览+搜索,Enter 关页。
- **减法**:删 iter-32 `PopupKind::ModelPick`/`ModelPick`/`build_model_popup`/`Popup.{kind,picks}` 及其 PopupApply 分支与 3 测试 —— 模型选择归入通用 Panel,`Popup` 回纯文本补全,现状不留两套。

## 对抗评审战果(正确性门禁)

- **一套原语复用五页**:不为每命令各写浮窗/渲染,统一 `Panel` + `panel_filter`/`panel_action` 纯函数 + `draw_panel` 一处渲染(YAGNI)。
- **借用安全**:`panel_enter` 先 clone 出选中项数据释放对 `ui.panel` 的不可变借用,再 mut `ui`/`meta`(NLL),避免 E0502。
- **减法诚实**:iter-32 的特例浮窗被通用页取代即删净,无两套模型选择器漂移。
- **live/持久化分层**:配置页编辑既持久化(`persist_config`)又对可即时生效键 live 应用;不可 live 的键明示「下次启动」。
- **验收纯函数化**:过滤/导航/路由/构造全纯函数直断言,`draw_panel` 渲染靠门禁编译 + 既有 `draw_only_when_dirty_or_busy`。
