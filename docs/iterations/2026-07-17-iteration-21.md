## 做了什么(`crates/agent/src/lib.rs`)
- **系统提示词硬化**:`BASE_SYSTEM` 注入三条 harness 物理契约(terse,英文续 existing 风格,保冻结前缀利缓存):
  - 大工具输出被截断为 head+tail 预览 → 取细节用 ranged read_file/search,勿反复巨读(对齐 iter-19)。
  - 勿删/清空测试来蒙混通过 → 被拦且算失败(前置对齐 iter-18 约束守卫,反奖励黑客)。
  - 用 signal_write 沉淀可复用发现/坑/待办 → 下个会话继承(对齐 iter-16/20 复利环)。
- **工具调用鲁棒**:`execute_tool_call` 未知工具默认臂 `"unknown tool"` → `"tool error: 未知工具 ..."`(含 " error:")。此前幻觉工具名不含判据词 → `is_error_observation`/`tool_output_failed` 皆 false → 静默空转不计错;改后喂 iter-18 熔断计数 + 失败信号,幻觉连发即早停。
