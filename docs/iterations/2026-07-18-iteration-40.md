# Iteration 40 报告 —— Hook 系统 + 四个内置 Hook

> maker = 用户需求「自定义 Hook + 补充必要 Hook」。checker = CONTRACT-iteration-40。价值门禁不适用(用户明确需求)。

## 做了什么

### Hook 引擎(config 声明,lib.rs)
- `HookCfg{event, matcher, command, blocking}` + Config `hooks`/`notify`。四事件 `pre_tool`/`post_tool`/`session_start`/`stop`;`matcher`=工具名子串(缺=全部工具)。
- 纯核:`hooks_for_event(hooks,event,tool)`(过滤)、`audit_line`。
- `run_hook_command`:跨平台(cmd/sh),经**带 `.env()` 的 Command** 注入 `RIDGE_TOOL`/`RIDGE_TOOL_ARG` —— **不设全局 env**,BSP 并发下多工具并发触发 hook 也不互串。
- `execute_tool_call`:前置 `run_pre_tool_hooks`(blocking hook 非 0 退出 → `BLOCKED`,工具不执行)、末尾 `run_post_tool_hooks`(match 值收进 `obs` 再 fire-and-forget)。

### 四个内置/必要 Hook
- **会话审计留痕**(始终开):`audit(event,detail)` 追加 `~/.ridge/audit.log`(前置 epoch 秒);`session_start` 与每个 `stop` 都留痕。
- **任务完成通知**:`notify=true` → 每任务毕响一声终端铃(`\x07`)。
- **写文件后格式化 / 危险操作前确认**:引擎原生支持(`post_tool`/`pre_tool`),作**示例 hook** 随 `install.ps1` 的 config.example.json 下发(命令项目相关,不硬编码进内核)。

### 触发点接线
- `main` 启动 `set_hooks`/`set_notify`/`fire_session_hooks("session_start")`;run_once/headless 任务毕 `fire_session_hooks("stop", steps)`;tui done 处理任务毕 `fire_session_hooks("stop", steps/tokens)`。

## 对抗评审战果(正确性门禁)
- **并发安全**:hook env 只挂单条 Command(非 `set_var` 全局)—— 直面 BSP 超步「同快照并发跑多节点」的现实,多工具并发触发 hook 不会串 env。
- **零副作用回归**:`HOOKS`/`NOTIFY` 未设时(所有既有测试)`active_hooks()` 空、`execute_tool_call` 的 pre/post hook 全空转 → 87 个既有工具/闭环测试无一受扰。
- **内核最小 + 安全**:只把**通用安全**的两个内置(审计/响铃)做进内核(纯内部、跨平台);格式化/危险确认这类**项目相关 shell** 走示例配置下发,遵「外置能力不硬进内核」铁律。
- **拦截语义确定**:`pre_tool` blocking 非 0(或起不来)→ BLOCKED,复用既有 `BLOCKED` 判据词进失败/熔断信号,与危险命令硬拦截同管道。
