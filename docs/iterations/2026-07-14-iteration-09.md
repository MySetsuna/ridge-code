## 1. 能力:联网搜索 + GFW 感知 + 引擎切换

给 agent 补上「查外部实时信息」的手(此前只能读本地/跑 shell)。核心是**先探网络、再按环境换引擎**:

- **网络探测** `detect_net`:GET Google 的 `generate_204` 探针 —— 通 → `International`(能直连国际网络,裸连或带 VPN/代理);不通 → `Restricted`(GFW 内)。
- **引擎切换** `web_search`:
  - `International` → **DuckDuckGo**(html 端点;解 `uddg=` 跳转参数拿**真实 URL**,而非 DDG 中转链)。
  - `Restricted` → **Bing 中国版 `cn.bing.com`**(墙内可达、静态 HTML 好解析;而 DuckDuckGo/Google 在墙内根本不可达 —— 这正是「换引擎」的必要性)。
- **架构**:全放在 `provider::search`(复用 reqwest,**零新依赖**)。HTTP 只走 `WebFetch` GET 接缝 → 测试注入假抓取器,**不联网可测**。HTML 解析纯 std(`strip_tags`/`urlencode`/`percent_decode`),不引 scraper/regex。
- **接进 agent**:`web_search` tool_spec + act 节点异步分支 + `web_search_obs`(懒探测一次、**缓存**网络环境、排版标题/链接/摘要给模型)。归**只读工具**,不打扰权限门。

## 2. 实测(智谱 GLM-4.5-air + 真实网络,零改代码)

`ridge "用 web_search 查 'Rust programming language official site'"`:
→ 探测 = **直连国际** → 引擎 = **duckduckgo** → 返回 `rust-lang.org` / `github.com/rust-lang/rust` / `doc.rust-lang.org` 等**真实链接**(`uddg` 已解码)→ `approved`。trace.json 记录「网络:直连国际 · 引擎:duckduckgo」的决策,交互透明。
