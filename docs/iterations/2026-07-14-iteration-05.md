- **本迭代主题**: 把 agent 内核变成「像 Claude Code 的 CLI 交互体验」

## 1. 本迭代做了什么(P0–P3 全部落地,含真实实测)

- **P0a 剥 `<think>` 标签**:`parse_response` 清掉思考模型漏进 content 的 `<think>...</think>` / 游离标签(Iter04 实测发现 GLM 会漏)。
- **P0b 多轮 `role=tool` 正确回灌**:新增 `AgentState.history: Vec<Message>` 作为模型面向的真实多轮历史;reason 推 assistant(带 tool_calls)、act 推 `tool_result`(匹配 `tool_call_id`),`to_messages = [system] + history`。不再把轨迹当 assistant 纯文本糊上去。
- **P1 交互式 REPL**:`ridge` 无参数 → 进对话循环,跨轮携带 `history` 实现多轮上下文;`/exit` `/reset` `/help` 命令。
- **P2 实时流式进度**:REPL 订阅引擎 `StreamEvent`,边跑边显 `· reason#1 · act#2 · reason#3 · verify#4`。
- **P3 权限门**:`Approver` trait(`AutoApprove` / `AutoDeny` / REPL 的 `StdinApprover`),有副作用的工具(shell / 写文件 / MCP)执行前 `[y/N]` 确认;只读工具(read_file)放行。

## 2. GLM 真实 REPL 实测(关键成果)

`ridge`(GLM-4.5-air)REPL 一次交互,四件事全部真实生效:

```
ridge> · reason#1
  ⚠ 允许 run_shell {"cmd":"cargo build"} ? [y/N] · act#2 · reason#3 · verify#4
verify: PASS (deterministic gate)
[approved=true steps=2 tokens=861]
ridge> bye.
```

—— `ridge>` 提示符 + 实时流式节点进度 + 危险操作 `[y/N]` 确认 + 模型看真实退出码收尾 + 回提示符不退进程。**用起来已经像 Claude Code**。
