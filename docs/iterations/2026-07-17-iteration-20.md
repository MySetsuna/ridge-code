## 做了什么

### 抽取器(`crates/agent/src/lib.rs`)
- `parse_extracted_signals(text) -> Vec<(kind, body)>` **纯函数**:每行 `kind: body`(中英冒号 `:`/`：` 皆认),kind ∈ {discovery, friction, todo},body 非空;`NONE`/越集 kind/空 body/无冒号/markdown 项目符号一律容错忽略;上限 `MAX_EXTRACTED_SIGNALS=5`。
- `run_has_substance(out)` + `signal_extract_request(out) -> Option<CompletionRequest>`:**抽取门** —— 无实质轨迹(未动工具且未改文件)→ 不抽,省一次 LLM 调用;有 `act:`/改文件 → 构造请求,轨迹复用 `bound_observation`(iter-19)有界化。
- `extract_signals_from_run(provider, out, dir, source)` 端到端:调 provider 一次 → 解析 → `signal_create` 落盘(内容哈希**幂等去重**)。best-effort:provider 错/解析空/无轨迹 → 空,**绝不掀翻主流程**。
- `signal_extract_enabled()`:opt-in,env `RIDGE_EXTRACT_SIGNALS` = 1/true/on/yes,默认关。

### 接线(`crates/agent/src/main.rs`)
- `trace_and_report` 改返 run 的 source id;`run_once`/`headless` 建 app 前留一把 provider(Arc 克隆廉价),收尾 `maybe_extract_signals` 复用同一 source id(溯源回指 `.ridge/runs/<id>`)。
- `--help` 列 `RIDGE_EXTRACT_SIGNALS`。
