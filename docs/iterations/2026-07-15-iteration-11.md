## 本轮六项(均 GLM 真实实测)

1. **多文件批量原子编辑 `apply_edits`**:一次跨文件多处编辑,汇总一份 diff **一次确认**,**原子**应用(全成/全不改,写失败回滚)。实测一次调用改 2 文件。
2. **token 逐字流式(SSE)**:provider 读 SSE 增量(文本 + **分片工具调用按 index 拼装** + usage),经 TokenBus 到 REPL 逐字显示;不支持流式的 provider **优雅降级**整段。假流式 HttpClient 单测(不用 mockito)。
3. **`--resume` 崩溃恢复**:REPL 每轮把对话 history 落盘;kill-9/关掉重开 `--resume` 续接多轮上下文。跨进程实测:新进程恢复并答对上轮的事实。
4. **`@file` 上下文引用**:输入里 `@path` 自动注入文件正文(存在才注、去重、截断)。实测模型不调工具一步答出文件里的密标。
5. **Ctrl-C 中断**:任务跑一半 Ctrl-C → 取消回提示符(不杀 REPL),`tokio::signal` 竞速。
6. **TODO 清单可视化 `todo_write`**(Claude Code 式 TodoWrite):模型维护 `{content,status}` 清单,REPL 边做边渲染 `[x]/[~]/[ ]`。实测多步任务逐步 `[ ]→[~]→[x]`。
